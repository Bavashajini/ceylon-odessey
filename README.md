# Ceylon Odyssey - Sri Lanka Travel Agency Webpage

A comprehensive Sri Lanka travel portal featuring precious unique district guides, interactive picture popup modals, transport & chauffeur guidance, budget-friendly hotel options (Small, Medium, High), an interactive trip cost estimator, customer reviews, FAQs, and dedicated contact desks for travellers, call taxi owners, and hotel managers.

---

## 🚀 How to Open and View This Webpage on Your Computer

You have **two easy options** to view this website locally:

### Option 1: Easiest & Fastest — Instant Double-Click (No Installation Required!)
1. Open the downloaded folder on your computer.
2. Find the file named **`standalone.html`**.
3. **Double-click `standalone.html`** (or right-click and choose *Open with Google Chrome*, *Edge*, *Safari*, or *Firefox*).
4. That's it! The entire webpage with all interactive district popups, budget filters, currency calculator, and contact forms will open and run smoothly in your browser immediately.

---

### Option 2: Running the React + Vite Development Server (For Developers)

If you have [Node.js](https://nodejs.org/) installed on your computer:

1. Open your terminal or Command Prompt in this folder.
2. Install the project dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

---

### Option 3: Viewing the Production Build

You can also serve the pre-built `dist/` directory using Python or `npx`:

```bash
# Using Python (built into Mac & Linux, or Windows Python):
python -m http.server 3000

# Or using Node npx:
npx serve dist
```
Then visit `http://localhost:3000` in your browser.

## 🌟 Key Features Included

1. **District Explorer with Popup on Picture Click**:
   - Covers iconic destinations: **Matale (Sigiriya & Dambulla)**, **Kandy**, **Badulla & Ella (Nine Arch Bridge)**, **Galle**, **Nuwara Eliya**, **Matara & Mirissa**, **Hambantota & Yala**, **Trincomalee**, **Jaffna**, **Colombo**, etc.
   - Clicking on any district photo opens the **District Detail Modal Popup** with precious places, best seasons, and local food specialties.

2. **Travel Guidance & Transport Facilities**:
   - The iconic Scenic Hill Country Blue Train (ticket procedure guide).
   - Dedicated Private AC Car/Van with Tourist Board Certified English-speaking Chauffeurs.
   - Call Taxi & Airport Transfers.
   - Local Tuk-Tuks and self-drive rentals.
   - Intercity Expressway luxury AC coaches.

3. **Hotel Stays with Budget-Friendly Options**:
   - **Small / Budget** ($15 – $35 / night | Rs. 4,500 – 10,500): Eco homestays, treehouses, surf lodges.
   - **Medium / Comfort** ($45 – $95 / night | Rs. 14,000 – 29,500): Boutique courtyard hotels, riverside resorts with pools.
   - **High / Luxury** ($130 – $450+ / night | Rs. 40,000 – 140,000+): 5-star colonial estates, private pool villas.

4. **Interactive Budget Estimator**:
   - Customize days, travelers, stay tier, and transport with live recalculation and currency switcher (USD, LKR, EUR, GBP).

5. **Customer Reviews & FAQs**:
   - Testimonials from international travelers + working review submission modal.
   - Detailed answers on visas, seasonal monsoons, and cultural temple dress codes.

6. **Dedicated Hotlines & Coordination Desks**:
